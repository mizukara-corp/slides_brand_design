# career-spirit-slides 使い方マニュアル

キャリスピブランドのPPTXスライドをClaude Codeで自動生成するスキルです。
TEMPLATE.pptx（24枚：base 6枚 + fixed 13枚 + fillable 5枚）のデザイン（オレンジ×ダーク・ブランドフォント・カラー）をそのまま引き継いで、テキストから完成資料を作ります。

---

## 1. このスキルでできること

- テキスト・アジェンダ・台本などからキャリスピブランドの **.pptx** を自動生成
- スライドタイプ（タイトル/セクション/カード/Q&A/プリセット図解…）を**自動選定**
- 既存PPTXへの**スライド追加・置換**（mode: edit）
- アイコン（ピクトグラム）を `card2` / `card3` / `content_list_4` / `agenda` に自動配置
- **bookend 機能**：先頭に title カバー、末尾に section_check ディバイダーを自動挿入
- 著作権表示は実行年（例：© 2026）に自動統一

---

## 2. 起動方法

Claude Codeのチャットで以下のいずれかをタイプ：

```
/career-spirit-slides
```

または通常の依頼文でもOK：

> キャリスピのスライドを作って
> DSの講義資料を作りたい
> キャリア・自己理解講座のスライドにして

スキルが自動的に起動して、最初に**準備状況を 4 択で聞いてきます**。

---

## 3. 4つの開始パターン（ユーザー状態）

スキル起動後、最初に下記が問われます。

| 番号 | 状態 | あなたの状況 |
|------|------|-------------|
| 1 | **何も決まっていない** | テーマすら決まっていない。一緒に考えたい |
| 2 | **テーマだけ決まっている** | 「キャリア自己理解」など漠然としたテーマだけ |
| 3 | **アジェンダがある** | 章立て・見出しはあるが各スライド中身は未定 |
| 4 | **内容が揃っている** | テキスト・台本・箇条書きを貼り付けるだけ |

→ 選んだ番号に応じてClaudeが対話の進め方を切り替えます。

> **ヒント**: 最初のメッセージに**スライドのテキスト・台本を直接貼り付ける**と、Claudeが状態 4 と判断して即生成モードに入ります（質問はスキップ）。

---

## 4. もっとも速い使い方（状態 4 / 直接生成）

```
/career-spirit-slides

以下の内容で15枚のスライドを作って：

スライド1：カバー
タイトル: コンフォートゾーンを使いこなす技術
サブ: キャリアに迷う20代・30代のための、脳科学 × 実践ワーク

スライド2：アジェンダ
ゴール: 戦略的にゾーンを出入りする技術を身につける
チャプター:
  - コンフォートゾーンの正体
  - 自分のゾーンを知る
  - 使いこなす5つの技術
  - 習慣化と1週間の設計
...
```

Claudeが内容を解釈して、**最適なスライドタイプを自動選定** → outline.yaml生成 → ビルド → QA画像確認 → ワークスペース保存まで一気通貫で進めます。

## 5. 利用できるスライドタイプ

### リッチテンプレート（動的テキスト注入・5枚）★最優先で使う

セミナーの**オープニング・章扉・比較構図**で使う。動的にテキスト枠を生成するためレイアウトはコードベース。

| type | 見た目 | 主な用途 |
|------|--------|---------|
| `cover` | ダーク・オレンジ光彩・SEMINAR/2026 + 大タイトル | デッキ表紙 |
| `agenda` | オレンジ×ダーク斜め分割・GOAL + CHAPTERS（01-04） | アジェンダ・章立て紹介 |
| `section_rich` | 黒/白分割・SECTION xx + 英語名 + 日本語タイトル | チャプター扉 |
| `card2` | 白背景・2つの角丸グレーカード（番号バッジ付き） | 対比、Before/After、2要素並列 |
| `card3` | 白背景・3つの角丸グレーカード（番号バッジ付き） | 3概念並列、3ステップ |

### ベーステンプレート（テキスト編集可・6枚）

| type | 見た目 | 主な用途 |
|------|--------|---------|
| `title_light` | 白背景・中央タイトル＋ロゴ | セクション小見出し、シンプルな表紙 |
| `question` | オレンジ背景・大きな"Q." | 問いかけ、気づきの誘発 |
| `answer` | 白背景・大きな"A." | 回答、キーメッセージ |
| `content_list_4` | 白背景・4つの番号付きボックス | 4要素整理 |
| `memo` | 白背景・大きな1行メッセージ | キーメッセージ、強調 |
| `profile` | 写真＋肩書き＋経歴リスト | 講師紹介 |

> 注意：`content_list_4` の連続使用はデッキが単調になる。`card2` / `card3` / `memo` / `answer` / preset を交互に挟むこと。

### プリセット（図解をそのまま使う）

- **fixed（13枚）**：色・図形・テキストすべて固定の図解（Be-Do-Have、Iceberg、Walls4、Goal-Brake、Step3-Cards など）
- **fillable（5枚）**：レイアウト固定でテキストだけ差し替え可能（flow4_horizontal、stats_card、before_after など）

> 詳細リストとフィールド一覧は [docs/yaml-template.md](yaml-template.md) を参照。

## 6. アイコン（ピクトグラム）

`card2` / `card3` / `content_list_4` / `agenda` ではアイコンを差し込んでビジュアルアクセントを加えられる。
背景はオレンジ（`#EC6F1A`）の円、前景は白で統一される。

```yaml
- type: card3
  title: "技術5: ゾーン拡張の記録"
  card1_title: "記録する"
  card1_icon: "pencil"          # アイコン名を指定するだけ
  card1_body: "越えられた境界を「拡張ログ」として記録"
  card2_title: "比較する"
  card2_icon: "compare"
  card2_body: "過去の自分のストレッチ＝今のコンフォート"
  card3_title: "効果"
  card3_icon: "growth_chart"
  card3_body: "自己効力感が蓄積／次の挑戦のハードルが下がる"
```

主なアイコン名（カテゴリ別）：

- **記録・学習**：`pencil`, `note`, `book`, `memo`
- **分析・思考**：`chart`, `growth_chart`, `target`, `lightbulb`, `brain`, `search`, `gear`, `flag`
- **動き・関係**：`compare`, `loop`, `arrow_right`, `chevron`, `growth`
- **強調**：`star`, `heart`, `lightning`, `check`, `explosion`
- **人・記号**：`people`, `plus`, `minus`, `no`, `equal`

> 全リストと例は SKILL.md の「アイコン（ピクトグラム）」セクション、または [docs/yaml-template.md](yaml-template.md) のアイコン早見表を参照。
> マッチしない文字列は絵文字/グリフとしてそのまま描画される（`"📝"` `"→"` `"Q"` など）。

## 7. 上手に使うコツ

### 入力テキストの書き方
- **見出しと本文を区切る**（「スライド1: 〜」「タイトル: 〜」など）
- 箇条書きは行頭の `-` `1.` `・` どれでもOK
- 丸数字（①②③）は使わない → **フォントで文字化けする**ので半角の `1.` `2.` `3.` に
- `content_list_4` の各項目は1行・短文（長いと枠から溢れる）

### スライド枚数の目安
- 30分セミナー：10〜15枚
- 1時間セミナー：20〜30枚
- 半日ワークショップ：30〜50枚

### デザインのコントロール
- 「対比で」「並列で」と指示すると `card2` / `card3` を選定
- 「問いかけたい」と伝えると `question` ／ 「答えを示したい」で `answer`
- 「セクション扉を入れて」で `section_rich` または `preset section_dark`
- 「数値を強調したい」で fillable の `stats_card`
- 「Before/Afterで」で fillable の `before_after`

### bookend（自動カバー・クロージング）
- デフォルト ON：`[title カバー]` + 中身 + `[section_check]` の構成になる
- カバーを自分で書きたいなら `cover: false`、または先頭に `cover` を置けば自動スキップ
- 末尾を変えたい場合は `closing: false`

---

## 8. 出力の流れ

スキル起動後、Claudeは以下を自動で行います：

1. **outline.yaml 作成**（`/tmp/outline.yaml` に書き出し）
2. **generate.py 実行** → `/tmp/output.pptx`
3. **PDF→JPEG変換でQA**：各スライドを画像化して目視確認
4. **問題があれば修正して再生成**（テキスト溢れ、丸数字文字化け、スロット名誤りなど）
5. **ワークスペース（プロジェクト直下）に保存**
6. （依頼があれば）`~/Downloads/` にコピー

---

## 9. 既存PPTXの編集

「既存の資料にスライドを3枚追加して」「途中に章扉を差し込んで」などの依頼にも対応します。

```yaml
mode: edit
input: /path/to/existing.pptx
position: end           # "end" または整数（0始まり）
bookend: false          # 既存ファイルへの追記なので false 推奨

slides:
  - type: question
    main_text: "追加する問いかけ"
```

> 詳細手順は [docs/yaml-template.md](yaml-template.md) の `mode: edit` 節を参照。

## 10. よくある質問・トラブル

| 症状 | 対処 |
|------|------|
| テキストが枠から溢れる | 行数を減らすか短い文に書き換える |
| `content_list_4` の項目が長くて崩れる | 1項目を1行・40字程度までに圧縮、または `card2`/`card3` に変更 |
| 丸数字が文字化けする | ①②③ を `1.` `2.` `3.` に変換 |
| `cover` を書いたのに自動カバーも入る | 先頭スライドが `cover` 型なら自動スキップされる。または `cover: false` |
| fillable のスロット名がエラー | [docs/yaml-template.md](yaml-template.md) でスロット名を再確認 |
| プリセットが見当たらない | `type: preset` + `name` の名前を SKILL.md / yaml-template.md で確認 |
| アイコンが表示されず番号バッジのまま | `card1_icon` 等のフィールド名スペル確認、または定義済アイコン名へ変更 |
| プロフィール写真を変えたい | SOURCE.pptx を PowerPoint で開いて手動置換 → `make_template.py` 再実行 |
| soffice 変換が失敗する | TEMPLATE.pptx を `make_template.py` で再生成（orphan slide を除去） |
| 生成PPTXが LibreOffice で開けない | `python -c "from pptx import Presentation; p=Presentation('out.pptx'); p.save('clean.pptx')"` で再保存 |
