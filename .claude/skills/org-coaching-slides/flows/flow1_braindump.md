# フロー①：ブレインダンプ（状態 1）

コンテンツが何も決まっていない状態。Claude がアジェンダを一緒に設計し、
状態 3 のフロー（flow2_agenda.md）へ引き継ぐ。

## ステップ A：前提収集（同時に 2 問）

```python
AskUserQuestion(
    header="この研修の対象者は？",
    options=[
        "1. 経営層・役員クラス",
        "2. リーダー・マネージャー層",
        "3. 一般メンバー（チーム単位）",
        "4. 1on1・個別コーチング",
    ]
)
AskUserQuestion(
    header="DAY 番号は？",
    options=["DAY 1", "DAY 2", "DAY 3", "DAY 4 以降"]
)
```

## ステップ B：「研修で受け取ってほしいこと」を自由記述で

```python
AskUserQuestion(
    header="この研修で参加者に最も受け取ってほしいことを書いてください",
    freeText=True,
    placeholder="例：自分のGOALに対するオーナーシップを獲得し、組織全体で合意できる状態を体感してほしい"
)
```

## ステップ C：Claude がアジェンダ案を提示

ステップ A・B で得た情報をもとに **3〜5 セクション構成のアジェンダ案** をテキストで提示。
組織コーチングの定番フレーム（Purpose → 認知 → 行動 → 合意 → 次のアクション）に沿わせると整いやすい。

例：
```
提案アジェンダ（DAY 1 / リーダー層向け）

1. Purpose / 本研修の目的
   → なぜ組織コーチングが必要なのかを共通言語にする
2. 結果を作る原理原則
   → 結果は信念→感情→行動から生まれることを理解する
3. 技術課題と適応課題
   → スキル習得で乗り越えられない課題があることを知る
4. 一致・合意・了解
   → 組織GOALを成立させる3レイヤーを区別する
5. 合意の意思決定モデル
   → 全員でオーナーシップを獲得するプロセスを設計する
```

## ステップ D：確認して flow2 へ引き継ぐ

```python
AskUserQuestion(
    header="このアジェンダで進めますか？",
    options=["このまま進める", "修正してから進める", "全部作り直す"]
)
```

- 「修正してから進める」 → 修正点を自由記述で受け取り、再提案
- 「このまま進める」 / 修正確定 → **flow2_agenda.md のステップ B へ**
   （アジェンダは確定済みとして扱う）
