# jcc-slides 使い方マニュアル

JCCブランドのPPTXスライドをClaude Codeで自動生成するスキルです。
TEMPLATE.pptxのデザイン（ダークネイビー背景・JCCロゴ・フォント・カラー）をそのまま引き継いで、テキストから完成資料を作ります。

---

## 1. このスキルでできること

- テキスト・アジェンダ・台本などからJCCブランドの **.pptx** を自動生成
- スライドタイプ（タイトル/セクション/箇条書き/カード/テーブル/プリセット図解…）を**自動選定**
- 既存PPTXへの**スライド追加・置換・削除**（編集モード）
- 著作権表示は実行年（例：© 2026）に自動統一

---

## 2. 起動方法

Claude Codeのチャットで以下のいずれかをタイプ：

```
/jcc-slides
```

または通常の依頼文でもOK：

> JCCのスライドを作って  
> DAY2の資料を作りたい  
> 講義スライドを新しく作って

スキルが自動的に起動して、最初に**準備状況を 4 択で聞いてきます**。

---

## 3. 4つの開始パターン（ユーザー状態）

スキル起動後、最初に下記が問われます。

| 番号 | 状態 | あなたの状況 |
|------|------|-------------|
| 1 | **何も決まっていない** | テーマすら決まっていない。一緒に考えたい |
| 2 | **テーマだけ決まっている** | 「コーチング」など漠然としたテーマだけ |
| 3 | **アジェンダがある** | 章立て・見出しはあるが各スライド中身は未定 |
| 4 | **内容が揃っている** | テキスト・箇条書きを貼り付けるだけ |

→ 選んだ番号に応じてClaudeが対話の進め方を切り替えます。

> ✅ **ヒント**: 最初のメッセージに**スライドのテキスト・台本を直接貼り付ける**と、Claudeが状態 4 と判断して即生成モードに入ります（質問はスキップ）。

---

## 4. もっとも速い使い方（状態 4 / 直接生成）

```
/jcc-slides

以下の内容で20枚のスライドを作って：

スライド1：タイトル
メイン: 〇〇セミナー
サブ: 〇〇〇〇

スライド2：アジェンダ
- 項目1
- 項目2
...
```

Claudeが内容を解釈して、**最適なスライドタイプを自動選定** → outline.yaml生成 → ビルド → QA画像確認 → ワークスペース保存まで一気通貫で進めます。

---

## 5. 利用できるスライドタイプ

### ベース（テキスト変更可）

| type | 見た目 | 主な用途 |
|------|--------|---------|
| `title` | ダーク・中央タイトル（JCCロゴ付き） | デッキ表紙、DAY見出し |
| `section` | ダーク・大見出し（英＋日 2行） | チャプター区切り |
| `content_list` | ダーク・左ラベル＋箇条書き | アジェンダ、ポイント整理 |
| `card2_dark` / `card2_light` | 2カラムカード | 対比、Before/After |
| `card3_dark` | 3カラム図解（番号付き） | 3概念の並列 |
| `table` | ダーク・2列テーブル | 対応表 |
| `memo` | ライト・引用ボックス | 名言、Key Message |
| `question` | ダーク・中央Question | 問いかけ、Q&A |

### プリセット（図解をそのまま使う）

- **fixed**：色・図形・テキストすべて固定の図解（Be-Do-Have、Coaching Matrixなど）
- **fillable**：レイアウト固定でテキストだけ差し替えできるテンプレート（MVV、Genjo Wave、FB-FFマトリクスなど）

> 詳細リストは [docs/preset-fixed.md](preset-fixed.md) と [docs/preset-fillable.md](preset-fillable.md) を参照。  
> Claudeはプリセット選択時にサムネイルグリッドを表示するので番号で選べます。

---

## 6. 上手に使うコツ

### 入力テキストの書き方
- **見出しと本文を区切る**（「スライド1: 〜」「タイトル: 〜」など）
- 箇条書きは行頭の `-` `1.` `・` どれでもOK
- 丸数字（①②③）は使わない → **フォントで文字化けする**ので半角の `1.` `2.` `3.` に
- 1スライドに詰め込みすぎない → **箇条書きは3〜5項目**が目安

### スライド枚数の目安
- 30分セミナー：10〜15枚
- 1時間セミナー：20〜30枚
- 半日ワークショップ：30〜50枚

### デザインのコントロール
- 「ダークで」「ライトで」と指示すると `card2_dark` / `card2_light` を切り替えてくれます
- 「対比で」「並列で」「カードで」など見せ方を伝えると最適なtypeを選びます

---

## 7. 出力の流れ

スキル起動後、Claudeは以下を自動で行います：

1. **outline.yaml 作成**（`/tmp/outline.yaml` に書き出し）
2. **generate.py 実行** → `/tmp/output.pptx`
3. **PDF→JPEG変換でQA**：各スライドを画像化して目視確認
4. **問題があれば修正して再生成**
5. **ワークスペース（プロジェクト直下）に保存**
6. （依頼があれば）`~/Downloads/` にコピー

---

## 8. 既存PPTXの編集

「DAY2.pptxにスライドを3枚追加して」「5枚目を差し替えて」などの依頼にも対応します。

- **edit モード**：末尾に追記
- **patch モード**：指定位置への挿入・置換・削除（`index` / `before` / `after` で位置指定）

> 詳細手順は [flows/flow5_edit.md](../flows/flow5_edit.md) を参照。

---

## 9. よくある質問・トラブル

| 症状 | 対処 |
|------|------|
| テキストが枠から溢れる | 行数を減らすか短い文に書き換える |
| テーブルの行が下で切れる | `rows` を5行以下に絞る |
| 丸数字が文字化け | ①②③ を `1.` `2.` `3.` に変換 |
| footnote に変な文字が残る | YAMLに `footnote: " "` を追加する |
| 日本語の長いタイトルが切れる | `title` で `title_text` + `subtitle` を使う（DAY形式の `day` ではなく） |
| プリセットが見当たらない | `docs/preset-fixed.md` / `preset-fillable.md` でname確認 |
| 生成PPTXが LibreOffice で開けない | `python -c "from pptx import Presentation; p=Presentation('out.pptx'); p.save('clean.pptx')"` で再保存 |

## 11. 例：実践セミナースライドを作る

```
/jcc-slides

「実践！コーチング・スキル向上セミナー」を20枚で作って

スライド1（タイトル）
メイン：実践！コーチング・スキル向上セミナー
サブ：相手の可能性を引き出し、行動を促す技術

スライド2（アジェンダ）
1. コーチングの概念と哲学
2. ティーチングとの使い分け
...
```

→ Claude が自動でtype選定 → 生成 → QA → 保存。完成したPPTXのパスがチャットに表示されます。
