# fixed プリセット一覧（16 種）

図解・フレームワーク図をそのままスライドに挿入する。テキスト変更不可。

```yaml
- type: preset
  name: <プリセット名>
```

サムネイル一覧 → `assets/thumbnails/fixed_grid.jpg`（4×4 グリッド）

---

### Be-Do-Have シリーズ（6 種）

| name | 説明 | 主な用途 |
|------|------|----------|
| `be_do_have_v1` | Do→Have→Be の基本図（行動/結果/マインド） | Be-Do-Have の概念導入 |
| `be_do_have_v2` | Do→Have→Be（自己否定→自己肯定感→自己効力感） | 心理的安全性の話 |
| `be_do_have_v3` | Do→Have→Be（Be を黄色ハイライト） | Be の重要性を強調 |
| `be_do_have_v4` | Do→Have→Be（行動/成果/マインド・別バリアント） | 組織版の Be-Do-Have |
| `be_do_have_v5` | Do→Have→Be（個人のマインド・黄色ハイライト） | 個人変容の文脈 |
| `be_do_have_v6` | Do→Have→Be（組織のカルチャー・黄色ハイライト） | 組織変革の文脈 |

```yaml
- type: preset
  name: be_do_have_v3
```

### コーチングマトリクス（2 種）

| name | 説明 | 主な用途 |
|------|------|----------|
| `coaching_matrix_v1` | 4 象限（事業軸 × 組織軸） | コーチングの射程範囲を説明 |
| `coaching_matrix_v2` | 4 象限（DO/BE × カルチャー/ピープル） | 組織コーチングの打ち手分類 |

---

### ビリーフ系（2 種）

| name | 説明 | 主な用途 |
|------|------|----------|
| `belief_system` | 入力→思考プロセス→出力 の認知バイアス図 | セクション 1 の概念導入 |
| `belief_bubbles` | ビリーフ バブル図（複数のビリーフが浮かぶ） | ビリーフ探索のワーク前説明 |

---

### GOAL マトリクス（2 種）

| name | 説明 | 主な用途 |
|------|------|----------|
| `goal_matrix_blank` | GOALマトリクス（4 象限・軸のみ・空白） | ワーク用の空白フレーム |
| `goal_matrix_filled` | GOALマトリクス（内容入り・記入例） | 記入例の提示 |

---

### その他（4 種）

| name | 説明 | 主な用途 |
|------|------|----------|
| `market_structure` | 普遍的な問題が生まれる市場の構造図（白背景） | 市場・ビジネス文脈の説明 |
| `logic3_highlight` | 思考 3 類型（黄色ハイライト版） | 論理・感情・直感の 3 軸説明 |
| `nonverbal_table` | 非言語情報テーブル（メラビアンの法則等） | コミュニケーション文脈 |
| `context3_table` | 3 つのコンテキスト テーブル | 状況・文脈の整理 |
