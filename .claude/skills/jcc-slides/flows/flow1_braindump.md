# フロー①：ブレインダンプ（状態 1）

コンテンツがゼロの状態。Claude がアジェンダを一緒に設計し、状態 3 のフローへ引き継ぐ。

## ステップ A：前提収集（2 問同時）

```python
AskUserQuestion(header="このスライドの対象者は？",
    options=["組織のリーダー層", "チームメンバー全員", "1on1・個別コーチング", "その他"])

AskUserQuestion(header="DAY 番号は？",
    options=["DAY 1", "DAY 2", "DAY 3", "DAY 4 以降"])
```

## ステップ B：伝えたいことを自由記述で収集

```python
AskUserQuestion(
    header="このセッションで参加者に最も受け取ってほしいことを自由に書いてください",
    freeText=True,
    placeholder="例：コーチングの本質は問いかけであることを体感してほしい"
)
```

## ステップ C：Claude がアジェンダ案を提示

受け取った情報をもとに、**3〜5 セクション構成のアジェンダ案**をテキストで提示する。
各セクションに「英語タイトル／日本語タイトル／伝えたいこと 1 行」を含める。

例：
```
提案アジェンダ（DAY 2）

1. PURPOSE / このセッションの目的
   → コーチングがなぜ組織に必要なのかを共有する

2. BE-DO-HAVE / マインドと行動の循環
   → Be から変えることの重要性を理解する

3. BELIEF SYSTEM / ビリーフシステムの仕組み
   → 認知バイアスが行動に与える影響を体感する

4. SUMMARY / まとめと宿題
   → 本日の学びを持ち帰りアクションに落とす
```

## ステップ D：確認

```python
AskUserQuestion(
    header="このアジェンダで進めますか？",
    options=["このまま進める", "修正してから進める", "全部作り直す"]
)
```

「修正してから進める」→ 修正点を自由記述で受け取り再提案
「このまま進める」/ 修正確定 → **flow2_agenda.md のステップ B へ**（アジェンダは確定済みとして扱う）
