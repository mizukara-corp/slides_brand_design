# フロー②：アジェンダ貼り付け（状態 3）

章立てはあるがスライド内容がまだの状態。アジェンダを受け取って各セクションの内容を収集する。

## ステップ A：アジェンダを受け取る

```python
AskUserQuestion(
    header="アジェンダを貼り付けてください（箇条書き・章立て・メモ書きで OK）",
    freeText=True,
    placeholder="例：\n1. コーチングとは\n2. Be-Do-Have\n3. ビリーフシステム\n..."
)
```

## ステップ B：Claude がアジェンダを解析

受け取ったアジェンダを解析して以下を確定する：
- セクション数とタイトル（英語・日本語）
- 各セクションで使いたいスライドタイプの初期候補

確認なしに次へ進む（ブレインダンプ経由の場合はアジェンダ確定済み）。

## ステップ C：各セクションの内容収集

セクション数だけ繰り返す。

**セクションごとの質問パターン：**

```python
# セクション N の内容収集（1セクションあたり最大 2 問）
AskUserQuestion(
    header=f"セクション {N}「{title_ja}」の内容",
    freeText=True,
    placeholder="箇条書き・メモ・文章 何でも OK。空白なら section スライドのみ生成します"
)
```

入力された内容から Claude が適切なスライドタイプを判断して YAML に変換する。

**スライドタイプの自動判断ルール：**

| 内容の特徴 | 使うタイプ |
|-----------|-----------|
| 箇条書き 3〜7 行 | `content_list` |
| 2 つの概念の対比 | `card2_dark` or `card2_light` |
| 3 つの段階・要素 | `card3_dark` |
| 表形式のデータ | `table` |
| 名言・引用・Key Message | `memo` |
| 問いかけ・ワーク | `question` |
| 内容が空 | `section` のみ |

## ステップ D：構成確認と生成

1. 全セクションの構成サマリーをテキストで表示
2. 確認 → YAML 生成 → スクリプト実行 → QA → 保存
