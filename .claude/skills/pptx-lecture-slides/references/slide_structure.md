# スライド構成リファレンス

## 標準スライド順序（44枚のフルテンプレート）

```
01  タイトル
02  アジェンダ
03  本講義のGOAL（3カードレイアウト）
04  本講義のTO BE（チェックリスト形式）
──────────── SECTION 01: 概念セクション ────────────
05  sectionSlide（セクション区切り）
06  概念の解説（図解：従来AI vs AIエージェント）
07  なぜ必要なのか？（課題→解決→3つの効果）
08  利点・欠点（左:メリット 右:デメリット）
09  事例紹介（3カラムカード）
10  ライブデモ
11  handsOnIntro（一緒にやってみよう！ イントロ）
12〜N stepSlides × N枚
──────────── SECTION 02: ハンズオン①（例：VS Codeインストール）────────────
N+1  全体像スライド（完成形ダイアグラム）※最初のハンズオン前のみ
N+2  sectionSlide
N+3  なぜやるか（3カードレイアウト）
N+4  handsOnIntro
N+5〜 stepSlides × N枚
──────────── SECTION 03: ハンズオン②③… ────────────
    sectionSlide
    なぜやるか
    handsOnIntro → stepSlides × N
    handsOnIntro → stepSlides × N
    （サブセクション数は内容に応じて追加）
──────────────────────────────────────────────────
    セキュリティ3原則（任意）
    完了チェックリスト
    次回への導線 ＆ 宿題
```

## 各スライドタイプの詳細

### 01 タイトルスライド
- ダーク背景（C.dark）+ 右上に大きな円デコ
- 上部ラベル（例: 'AI実践シリーズ'）
- メインタイトル（大文字 46pt）
- サブタイトル（16pt、C.purpleLight）
- 対象・所要時間テキスト（下部）

### 02 アジェンダ
- 白背景 + 上部パープルライン
- タイトル「アジェンダ」
- 行ごとに番号（01〜05等）+ タイトル + 説明テキスト
- 各行高 0.73"、交互グレー背景

### 03 本講義のGOAL
- タイトル「本講義のGOAL」
- パープル横断バナー（メインコンセプト1文）
- threeCards(): num='01'〜'03'、title、items×2

### 04 本講義のTO BE
- タイトル「本講義のTO BE」
- 行リスト形式: label（DONE/宿題）+ テキスト
- DONEは緑背景、宿題はアンバー背景

### 概念の解説（図解推奨）
- 2パネル比較が効果的
- 左: 従来の方法（グレートーン）
- 右: AIエージェント・新しい方法（パープル）
- フロー図（[箱] → [箱] → [結果]）+ まとめテキスト

### なぜ必要なのか？
- 課題ボックス（赤左ライン）
- 矢印テキスト
- 解決ボックス（緑）
- threeCards()（メリット3つ）

### 利点・欠点
- 左カード（緑ヘッダー）: 利点リスト × 5（✓ マーク）
- 右カード（赤ヘッダー）: 欠点リスト × 5（✗ マーク）
- 下部アンバーバー: まとめメッセージ

### 事例紹介（3カラムカード）
```javascript
// 1カード構成（cardW=3.0"）
// ヘッダー（パープル）: 番号 + タイトル
// 指示例ボックス（アンバー）: プロンプト例
// Before ボックス（グレー）
// 矢印 ↓
// After ボックス（緑）
```

### ライブデモ
- パープルバナー（説明テキスト）
- デモ項目リスト（D1, D2... ＋ ★ハイライト）

### 全体像スライド（ダイアグラム）
- タイトル「今日作る『完成形』を確認しよう」
- 大きな外枠ボックス（VS Code）
- 内側に Claude Code ボックス
- 外部サービスボックス（Slack/Calendar/Files）
- 矢印（あなた → Claude Code → 外部）
- 下部に今日のステップ行

### 完了チェックリスト
- 緑ヘッダーライン
- チェック行リスト（緑丸 + ✓ + テキスト）

### 次回への導線 ＆ 宿題
- ダーク背景
- 宿題ボックス（説明付き）
- 手順行リスト（1〜3: C.darkRow背景+白テキスト、最終: C.purple+アンバードット）
- TIPS テキスト（下部）

## コーディング上の注意事項

### 絵文字について
LibreOffice での PDF 変換時、U+1F000 以上のマルチコードポイント絵文字は「?」ボックスに化ける。
- 使ってよい: ✓（U+2713）✗（U+2717）→ ↓ ★
- 使ってはいけない: 🎉🔧💡📁 など（すべての絵文字）
- 代替: テキストラベル（OK / NG / DONE / STOP / CHECK）、彩色ボックス

### シャドウ
シャドウオブジェクトは使い回しNG。必ず `shadow: S()` と関数呼び出しで毎回生成すること。

### カラーコード
pptxgenjs は6桁 RGB のみ受け付ける。8桁（透過付き）は無効。
透明度は `fill: { color: 'XXXXXX', transparency: 50 }` で指定する。

### テキスト内改行
pptxgenjs でテキスト内改行が必要な場合は配列形式を使う:
```javascript
sl.addText([
  { text: '1行目', options: { breakLine: true } },
  { text: '2行目' }
], { x:..., y:..., ... });
```

### レイアウト座標系
- LAYOUT_16x9 = 10" × 5.625"
- すべての座標（x, y, w, h）はインチ単位
- コンテンツエリアは x: 0.3〜9.7"、y: 1.32〜5.4"（ヘッダー後）

## よく使うパターン

### 白背景コンテンツスライド（標準）
```javascript
const sl = pres.addSlide();
sl.background = { color: C.white };
contentHeader(sl, 'SECTION 01', 'スライドタイトル');
// y: 1.32 以降にコンテンツを配置
```

### 情報カード（ボーダー付き）
```javascript
sl.addShape(pres.shapes.RECTANGLE, {
  x: 0.3, y: 1.32, w: 9.4, h: 0.75,
  fill: { color: C.cardBg }, line: { color: C.border }
});
sl.addText('テキスト', {
  x: 0.5, y: 1.32, w: 9.2, h: 0.75,
  fontSize: 14, color: C.textDark, fontFace: 'Calibri', valign: 'middle'
});
```

### 左ライン付きカード（赤/緑/パープルで強調）
```javascript
sl.addShape(pres.shapes.RECTANGLE, { x: 0.3, y, w: 9.4, h: 0.75, fill: { color: C.greenLight }, line: { color: C.greenBorder } });
sl.addShape(pres.shapes.RECTANGLE, { x: 0.3, y, w: 0.07, h: 0.75, fill: { color: C.green }, line: { color: C.green } });
```
